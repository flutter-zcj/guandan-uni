# 掼蛋 UI 对齐度分析（自研 Phaser 版 vs 原版 APK）

> 分析方法：原版数据全部来自 APK 实测（还原被混淆的 PNG 后采样主色、解析 plist 图集帧尺寸、
> 提取 csb 节点名/资源清单）；当前实现数据来自 `src/game/` 源码常量。
> **合规**：只取色值、尺寸、结构等客观参数用于程序化重绘，不提取任何原版美术素材。

## 一、总体结论

| 维度 | 对齐度 | 说明 |
|---|---|---|
| 布局结构 | ★★★★☆ 85% | 1280×720、四家布局、南家大牌+其余牌背、中央出牌区，结构一致 |
| 元素尺寸 | ★★☆☆☆ 45% | 手牌/出牌区牌明显偏小 |
| 配色 | ★★☆☆☆ 50% | 按钮三色与原版完全相反 |
| 装饰元素 | ★☆☆☆☆ 30% | 缺桌面中央 LOGO、名次底图、抗贡图 |
| 动效 | ★☆☆☆☆ 20% | 原版有炸弹/牌型/胜负特效，当前仅 toast 淡出 |
| **综合** | **≈ 55%** | 骨架对，皮肤与动效差距大 |

| 牌面宽高比 | 0.732 | 0.708 | 基本一致 |

## 六、如何复现本分析

```bash
# 原版资源位于 /workspace/guandan-reverse（已解密 Lua）与 APK assets
# PNG 混淆规则：首字节 0x89→0x88，且 IHDR 的 4 字节 length 字段被清零
# 修复方式：d[0]=0x89; d[8:12]=struct.pack('>I',13) 即可被 PIL 正常解码
```
